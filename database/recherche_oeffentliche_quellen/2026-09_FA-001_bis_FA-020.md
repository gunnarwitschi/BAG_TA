# Öffentliche Recherche – technische Architektur FA-001 bis FA-020

Stand: 16.09.2026  
Basis: öffentliche Quellen; nur belastbare technische Erkenntnisse werden als Modellierungskandidaten ausgewiesen.

## Modellierungsregel

- FA verwendet primär TV bzw. HPV.
- Wenn die konkrete Version noch unbekannt ist, kann temporär FA → T bzw. FA → HP verwendet werden.
- TG ist fachanwendungsunabhängig und gruppiert T.
- Eine Plattform bzw. ein Application Cluster ist **keine Technologie** und wird nicht als T/TV modelliert.
- Keine konkreten Versionen ohne belastbaren Nachweis.

## FA-020 – Data Analytics Platform (Sektion DAT)

### Gefunden
Die öffentliche Dokumentation beschreibt eine zentrale Datenanalyseplattform mit:
- Zusammenführung verschiedener Datenquellen
- Datenbereinigung
- Plausibilisierung
- Datenverknüpfung
- automatisierten Analyse-Pipelines
- automatisierten Tests
- Bereitstellung und kollaborativer Bearbeitung von Code
- Statistik
- Modellierung
- Machine Learning

Die während COVID aufgebaute Plattform wird im DigiSanté-Kontext als Diseases Data Analytics Platform weiterentwickelt.

### Modellierung
Die Plattform selbst ist **keine einzelne Technologie**. Die öffentlich belegten Fähigkeiten sind Architekturkontext. Konkrete Produkte wie Posit, Airflow, SQL Server, Dell ECS usw. werden **nicht** allein aufgrund dieser öffentlichen Beschreibung der FA zugeordnet.

### Quellen
- https://www.pandemieplan.admin.ch/de/ueberwachung-digitale-datenfluesse
- DigiSanté Botschaft zum Verpflichtungskredit
